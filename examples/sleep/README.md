# 公开 sleep 配对软件验收

来源为 [R datasets::sleep](https://stat.ethz.ch/R-manual/R-devel/library/datasets/html/sleep.html)。
官方说明20条记录对应10个人的两次测量，ID 标识对象；group 是药物条件，不能
解释成两组互不相关的人。extra 是相对对照增加的睡眠小时。这里只做软件验收。

在仓库运行 Rscript --vanilla examples/sleep/prepare-sleep.R 新的输出目录，生成
原20行、按确切 ID 重排的10行宽表和 R 环境。宽表保留两侧原始行号；转换代码
显式匹配 ID/条件，不用默认行序猜配对。原数据未随源码分发。

新建研究，导入 sleep-wide.csv；方法选配对 t 检验，ID列为 ID，第一列 drug1、
第二列 drug2，双侧95%、完整配对。核对声明和10对计数后确认。图表用现有
散点图，横轴 drug1、纵轴 drug2，一点对应一对。笔记保留分析/图表链接与单位。

独立60位精度参考：drug1减drug2的均值差-1.58小时，自由度9，
t约-4.06212768327，双侧p约0.00283289019738。原始数据、转换步骤及软件能力
不证明随机化、跨对象独立性、差值正态、周期/残留效应或临床有效性。
此结果用于比较软件数值和来源链，不作治疗建议。

方法、参数、失败处理和导出说明见 [配对检验](../../PAIRED-T-TEST.md)。
