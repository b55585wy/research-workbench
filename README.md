# Synrise Neuro · 文献与笔记

产品整体方向与近期迭代见 [PRODUCT-PLAN.md](PRODUCT-PLAN.md)，版本交付见 [ROADMAP.md](ROADMAP.md)。

当前版本 v0.14.0：PDF 阅读、出处笔记、图片标注、Python/R 分析、Notebook、SPSS 文件导入与可停止恢复的连续研究任务；新增“两组观测点”，按确切组别展示每条有效观测，保留组内数量和缺失排除信息。
PDF.js 嵌入我们的页面，FastAPI/SQLite 保存资料与笔记，PDFium 在独立子进程中生成区域图片。
没有部署 eLabFTW、RSpace 或 JupyterLab，也不依赖 tFUS 数据库和运行进程。

## 本机启动（Windows PowerShell）

在本目录运行；Python 3.12 已验证。首次准备依赖和本地 PDF.js 资源：

```powershell
python -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r requirements.txt
& .\.venv\Scripts\python.exe scripts\prepare_assets.py
& .\.venv\Scripts\python.exe scripts\prepare_notebook_assets.py
& .\.venv\Scripts\python.exe scripts\prepare_rich_text_assets.py
& .\.venv\Scripts\python.exe scripts\prepare_image_annotation_assets.py
& .\.venv\Scripts\python.exe scripts\prepare_plotly_assets.py
& .\.venv\Scripts\python.exe -m research_workbench --port 3150
```

然后打开 http://127.0.0.1:3150 。依赖及资源准备完毕后，阅读和笔记无需访问外部服务。
Notebook 资源准备另需 Node.js/npm；构建从锁文件取得上游组件，部署后的查看不需要 Node.js、CDN 或 Notebook 服务。
可添加自己的 PDF，或点击“试读示例”。示例是明确标记的合成阅读材料，不是科研证据。

## 上传、搜索与书目信息

左侧“上传 PDF”可添加论文。同一 PDF 再次上传会打开已有文献，保留笔记和书目信息；同名但内容不同的文件分别保存。支持本机不超过 20 MiB / 200 页的未加密 PDF。

搜索覆盖已保存的标题、作者、年份、DOI、原始文件名和当前有效笔记内容；支持中文和大小写无关的文字匹配。笔记结果可跳回原文页码与框选位置。已删除笔记及修改前的旧文字不进入搜索；本轮不检索 PDF 全文或进行 OCR。

阅读区展开“书目信息”可编辑标题、作者、年份和 DOI，支持保存、取消与冲突提示。作者和 DOI 为手动文本，年份可留空；这些信息不会自动联网验证。未保存的书目信息需先保存或取消再导出。书目、笔记和原文文件分别保存，改书目不改 PDF。

顶部主题选择提供默认与“哆啦A梦蓝”。后者用蓝白圆润控件统一资料区、工具和弹窗，
品牌保留“Synrise Neuro”文字，按反馈移除了左侧图标和口袋弧线。选择保存在当前浏览器；原文、图片、
科学图表和笔记内容保持完整，默认中性主题仍可切换。

## 图片查看与标注

上传图片和已保存的 PDF 图片摘录旁可打开“查看/批注”，放大、平移、框选矩形并填写说明。
画框先产生草稿，明确保存后才写入；支持修改、删除、恢复和失败后的原请求重试。
上传图片使用 EXIF 规范化预览，原图仍可下载；PDF 摘录使用保存的 PNG。
图片标注与 PDF 页面坐标分别保存，原文件保持不变。阅读导出包包含独立标注 JSON、
精确图片文件与可离线查看的静态标注。详见 [IMAGE-ANNOTATIONS.md](IMAGE-ANNOTATIONS.md)。

打开图片会提供助手的图片来源/标注文字上下文；图片像素仍需单独勾选“用于助手”。
PDF 摘录像素本轮不发送。助手的标注建议可预览，逐项确认后才保存。

## 实验图表

独立样本 t 检验在“数据与分析”的方法选择中使用：明确一个数值结果列、两组顺序、
Student/Welch、方向、置信水平及独立样本声明，预览后确认运行。计算直接复用现有
R stats::t.test，保存原始结果、参数与版本，支持 Notebook、引用和导出。
这是首个统计方法；SPSS .sav/.zsav 文件导入已支持，但没有 SPSS 引擎或语法执行器。jmv 在隔离验证中异常退出，未部署。
启动时需显式添加 --rscript 和 --statistics-root；详见 [STATISTICAL-TESTS.md](STATISTICAL-TESTS.md)。

在“实验图表”选择已上传数据，可绘制单列分布、双列成对散点，或从成功的
Python/R 分析生成有效/缺失数对比。先预览、核对字段和排除行数，再明确保存。
跨指标柱图只比较数量；不自动推断单位、组别、重复测量或统计显著性。
图表绑定数据、参数、计算与渲染版本。保存后重绘形成新记录，可删除和恢复。
支持放大、平移、查看数值、下载 PNG、加入笔记草稿与独立 ZIP 导出。
解压后打开 chart.html 可离线交互查看，原始表格和图表数据均附校验值。

明确勾选提供给助手的数据后，Agent 可查看绘图能力、计算只读预览、提出具体
方案；页面预览成功并确认后才保存。模型只接收有限数据样例和图表摘要，不会
自动取得完整数据或图表像素。图表链接能回到确切保存记录。详见 [CHARTS.md](CHARTS.md)。

当前为本机单人应用，尚无登录、多用户权限 API 或已实现的跨服务认证 actor
接入；来源标签不代表已认证用户。tFUS 主工程已确定首版使用其本地成员账号，
W10-A 的 Actor/账号基础源码已完成部分验收但尚未部署、全入口授权未完。
工作台后续沿用该身份来源，另行完成可信身份接入及资源授权后才能多人使用。
当前状态与接入边界见 [ACCOUNT-INTEGRATION.md](ACCOUNT-INTEGRATION.md)。

## 图表摘录与导出

框选原文区域、填写说明后，点击“保存图片摘录”；已有区域笔记可直接点击
“生成图片摘录”。图片下保留原文入口，生成失败可以重试，已保存的文字笔记保持。

“导出阅读记录”下载一个 ZIP。解压后打开 `index.html` 即可在浏览器离线查看，
也提供 `README.md`、`notes.json`、`images/`、原始 `source.pdf` 与校验清单。
原文链接定位到 PDF 页码，精确框选位置保存在 JSON 中。图片是视觉摘录，
不会把表格数字自动转换成结构化数据。

## 修改、复核与恢复笔记

点击笔记框旁的“格式编辑”，使用粗体、斜体、下划线、标题、列表和 HTTP(S) 链接；“应用到草稿”只更新当前草稿，再点击原来的保存按钮才写入。取消或按 Escape 不改变草稿。带格式的正文框保持只读，可以继续格式编辑，或明确“转为纯文本”。创建草稿和已有笔记的编辑草稿分别保留。

格式与正文在同一事务保存，共用修订号；格式修改也会回到待核对状态。删除、恢复、图片关联和原文出处仍使用同一条笔记。HTML 导出保留格式，JSON 保留结构和正文，Markdown 保留安全可读正文。现有纯文本笔记不自动转换。原编辑器来自 Quill 2.0.3，输入和显示经过格式白名单与 DOMPurify 校验；不接收任意 HTML 或内嵌远程图片。详见 [RICH-NOTES.md](RICH-NOTES.md)。

已有笔记可以修改文字、取消编辑，或移入“已删除笔记”后恢复。出处、原始创建内容和图片保留；恢复后仍使用原来的笔记与图片。手动“已核对原文”只记录本机使用者的阅读确认，不代表身份认证或科学验证。修改文字会重新变为待核对；原有 AI 笔记默认待核对。

导出包含当前文字和复核状态，并排除已删除笔记及其图片。编辑中或保存中需先完成或取消编辑再导出。两个页面同时修改同一笔记时，过期保存会提示冲突并保留草稿；查看最新内容后可明确取消旧编辑，再重新修改。详见 [NOTE-REVISION-AND-REVIEW.md](NOTE-REVISION-AND-REVIEW.md)。

## 图片与研究助手

右侧“图片库”可上传静态 PNG、JPEG、WebP。每张图片可分别勾选“加入新笔记”或“提供给助手”；上传本身不会发送给模型。支持每张最多 8 MiB、每篇最多 200 张且总存储最多 256 MiB，一次最多选择 4 张。原图保留，预览会规范化并移除元数据。上传图明确标记为用户提供，不能当作来自 PDF 的证据。

打开“研究助手”，发送时会固定当前论文、页码、框选位置、当前笔记及选中的图片。助手读取该页可提取的文字，结合当前笔记和最近对话回答，也能查询本地文献/笔记。框选只提供位置，暂不对框内自动截图或 OCR；扫描页没有可提取文字时会提示。助手可提出新笔记、修改/删除/恢复笔记、修改书目信息的具体方案；经你逐项确认后才保存，与手动操作使用同一份记录。复核原文仍需手动完成。

发送会把必要的阅读文字、笔记、书目信息、最近对话和所选图片预览发送给配置的模型服务；原始 PDF 不会整份发送。会话、来源、工具进度与确认结果保存在本机，重启后可查看。连接中断保留原请求供重试；取消后阻止后续写入，已经提交给外部模型的推理不保证立即停止。普通阅读和笔记仍可离线使用。

模型配置折叠在助手底部，仅保存到本工作台。也可在启动时传入 `--agent-config 绝对配置路径`，或使用 `RESEARCH_AGENT_CONFIG`，只读消费兼容的连接配置；本工作台自己的配置优先。当前本机复用 tFUS 模型连接的私有快照，未修改 tFUS 配置；原系统密钥轮换不会自动更新该快照。这只复用了模型连接，账号、权限和业务结果接入尚未完成。接口和运行约束见 [AGENT-AND-IMAGES.md](AGENT-AND-IMAGES.md)。

导出会附带有效笔记关联的上传原图、预览和来源标记；不附带未关联图片、已删除笔记或助手聊天记录。

## 数据与 Python/R 分析

“导入 SPSS”支持 `.sav/.zsav`：保留原文件，展示变量/值标签、测量级别、格式和缺失规则，
核对后再确认生成分析表。编码不换成标签；系统与声明的用户缺失转成空值，日期使用可表示的 ISO 文本。
确认不会自动运行分析或向 Agent 共享数据。分析导出同时保留原文件、字段字典和转换记录。
限制与接口见 [DATA-IMPORTS.md](DATA-IMPORTS.md)。CSV/TSV 原有上传流程保持可用。

SPSS 读取部件采用独立环境；Windows/Python 3.12 的锁定安装命令如下（目标目录须为新目录）：

```powershell
python scripts/prepare_import_runtime.py --root E:\research-workbench-runtime\research-import-v1
python -m research_workbench --port 3150 --import-root E:\research-workbench-runtime\research-import-v1
```

也可通过 `RESEARCH_IMPORT_ROOT` 指定该运行目录。未配置时仅 SPSS 导入不可用，不影响原有阅读和表格分析。

展开右侧“数据与分析”，上传 UTF-8 CSV/TSV，查看预览并选择数值列及 Python 或 R；点击“查看并准备运行”，核对数据、参数和完整代码，再确认运行。支持非缺失数、缺失数、均值、中位数、样本标准差、最小值和最大值；单个有效值的标准差为空。只有空单元格视为缺失，`NA` 等字符串不会被悄悄转成缺失值。所选列的所有非空内容必须是有限数值。

本轮运行固定、可审阅、带版本与校验值的描述统计代码。Python 使用标准库，R 使用 base R；计算进程与网页、模型调用及 tFUS 评分队列分开。输入、规范化数据、代码、参数、实际语言版本、日志与结果均可追溯。完成后可查看表格及有效值数量图，或导出独立分析 ZIP；解压打开 `index.html` 可离线查看。阅读记录 ZIP 的格式保持不变。

完成的任务可点击“查看 Notebook”，同时查看该次实际保存的代码、日志、结果表格和图表；视图不会运行或修改代码。下载 `.ipynb` 与分析 ZIP 内的 `analysis.ipynb` 使用同一份校验记录。查看限 1 MiB，数据或产物校验失败会明确报错。组件为 RSpace 使用的独立上游 JupyterKit 3.0.0，保留原渲染实现和许可；这是组件复用，不是 RSpace 业务模块抽取。详见 [NOTEBOOK-VIEW.md](NOTEBOOK-VIEW.md) 和 [SOURCE-REUSE-PLAN.md](SOURCE-REUSE-PLAN.md)。

数据文件与论文的关联由使用者指定，不证明它来自该论文。勾选“提供给助手”后，发送消息会共享该数据的元信息和最多 5 行预览；整份表格不发给模型。助手可提出 Python/R 分析，经你确认后排队，再读取已完成且校验通过的真实结果；结果笔记保留分析记录链接。排队、运行、失败、中断与完成分别显示。取消后不发布晚到的结果；服务重启保留未完成记录为中断，需明确重新发起。

当选中的分析属于明确共享的数据时，发送消息也会固定这条分析的标识；助手可读取其已校验的保存代码和输出。打开 Notebook 本身不会发送资料给模型。

支持每个文件最多 5 MiB、50 列、50,000 行，每篇文献最多 20 份数据及 20 条分析记录，最多 3 个待处理/运行任务；计算进程限时 30 秒，成功产物每次最多 20 MiB、每篇最多 128 MiB。输出需经过校验，失败不会显示为有效结果。这些软件检查不构成科研或医学验证。

Python 随当前运行环境可用。R 为可选独立运行时：安装官方 R 后，启动时传入 `--rscript Rscript完整路径`，或设置 `RESEARCH_RSCRIPT`；没有可用 R 时，界面会明确显示不可用。当前本机已在专用目录配置 R 4.6.2，无全局 PATH 或文件关联改动。自定义脚本、任意包安装、在线数据发现/下载、共享工作空间及 tFUS 账号/业务接入仍待后续。进程边界不等于通用代码沙箱。详见 [ANALYSIS.md](ANALYSIS.md)。

## 数据与使用范围

默认数据目录为本目录 `data/`：`workspace.sqlite3` 保存资料元信息和笔记，
`documents/` 保存原始 PDF。可通过 `--data 绝对目录` 或环境变量
`RESEARCH_WORKBENCH_DATA` 指定独立存储。停止服务后复制整个数据目录进行备份；
恢复时使用同一版本并指向恢复后的目录，不覆盖另一个正在写入的实例。
`excerpts/` 保存已生成的图片；`exports/` 仅用于导出期间的临时文件。
`images/` 保存上传原图和预览；会话和提案保存在 SQLite；`.agent-model.json` 为可选的私有模型配置，备份时单独保护凭据，不放入分享文件。
`datasets/` 保存原始表格，`analyses/` 保存分析输入与产物；可用分析记录的所有文件都应随数据库一起备份。
v0.6 将数据库从版本 1/2/3/4/5 升级到版本 6，保留已有资料、笔记、图片、会话与提案，新增数据和分析记录；升级前备份整个数据目录。旧版程序不能打开升级后的数据库，回退需使用升级前备份。
v0.7 继续使用版本 6 和原有 16 张表，Notebook 按已保存产物生成，不新增数据实体或迁移。
v0.8 将 schema6 升级为7，新增一张稀疏格式表，保留原有16张表的数据和原文件。旧版本无法打开升级后的库，回退时应恢复升级前备份。文件同步与完整备份的边界见 [STORAGE-AND-BACKUP.md](STORAGE-AND-BACKUP.md)。

首版仅本机单人使用，监听 127.0.0.1；没有账号、共享工作空间或远程开放能力。
文件限制 20 MiB / 200 页，不支持加密 PDF、OCR、自动摘图或在线分析。
PDF 检查使用独立子进程及超时/并发限制，这不等于安全沙箱。
笔记支持整页或框选区域出处；暂不编辑 PDF 本身。
手动图表摘录最长边 2048 像素、最多 400 万像素 / 8 MiB；导出原始输入最多 128 MiB。

## 阅读与分析工作区

顶部“阅读 / 数据分析”切换当前任务。分析时数据预览、方法设置、结果和图表占据中央，
笔记与助手按需展开；统一入口接受 CSV、TSV、SAV、ZSAV，后两种格式仍需核对确认。
切换视图不执行分析，也不自动向助手提供数据。流程与边界见 [WORKSPACE-WORKFLOW.md](WORKSPACE-WORKFLOW.md)。

明确共享数据后，可在助手中开启“连续完成分析、图表和笔记”。只需输入一次目标，
分析实际成功后自动生成图表提案，图表确认后自动生成来源笔记提案；每次写入仍需确认。
支持停止接续及核对原来源后继续，重启后暂停。v0.13 升级 schema10 到11，
新增两张任务表，保留原有22张表。使用、恢复、备份与接口见 [AGENT-TASKS.md](AGENT-TASKS.md)。
